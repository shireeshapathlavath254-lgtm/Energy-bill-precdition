# Energy Optimization Chatbot

## Overview
Energy Optimization Chatbot is a Streamlit-based web application that helps users calculate electricity consumption and estimate monthly electricity costs.

## Features
- Electricity consumption calculation
- Monthly bill estimation
- Energy-saving recommendations
- User-friendly interface

## Technologies Used
- Python
- Streamlit

## Run the Project

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
